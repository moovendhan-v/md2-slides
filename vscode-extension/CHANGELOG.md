# Changelog

## 0.1.0

- First release: open Markdown decks as slides beside the editor, or with "Open With… → Slidewise Slides".
- Live two-way sync with the text editor; the preview follows the cursor and "jump to source" moves it.
- Components view: drag slides and components to reorder them, edit raw Markdown in place.
- Customize panel (theme, fonts, layout, motion) and full presenter mode.
- Suggests opening Markdown decks as slides when they are opened (`slidewise.suggestOnOpen`).
